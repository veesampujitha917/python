## Project Overview

This repository contains 10 beginner-friendly Python case studies prepared as part of the Activity-Based Learning assignment. Each case study demonstrates problem-solving using Python input/output, arithmetic operations, conditional statements, and loops.

## Case Studies

1. **Progressive Electricity Billing** — Calculates an electricity bill using progressive unit slabs.
2. **Hospital Billing and Patient Classification** — Calculates hospital charges and classifies the total bill.
3. **Employee Payroll and Deduction Analysis** — Calculates allowances, gross salary, deductions, and net salary.
4. **Retail Billing with Multiple Discount Rules** — Applies a discount based on the purchase amount.
5. **Manufacturing Cost and Profitability Analysis** — Calculates production cost, revenue, and profit or loss.
6. **Multi-Currency Travel Budget Analysis** — Converts an INR budget using a user-provided exchange rate.
7. **Campus Event Financial Planning** — Compares event income with expenses and reports the balance.
8. **Examination Result and Grace-Mark Validation** — Checks marks and demonstrates a sample pass/grace/fail classification.
9. **Attendance Recovery Computation** — Calculates attendance percentage and estimates the additional classes needed to reach 75%.
10. **ATM Transaction Sequence Simulation** — Simulates balance checking, deposits, withdrawals, and exiting an ATM menu.

## Requirements

- Python 3.x
- Any Python editor, such as Visual Studio Code

## How to Run

1. Install Python 3 if it is not already installed.
2. Open the project folder in Visual Studio Code or another Python editor.
3. Open the `.py` file for the case study you want to run.
4. Run the program.
5. Enter the requested input values and check the output.

Example command in a terminal:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python program file.

## Important Notes

- The rates and thresholds used in these examples are for educational demonstration only.
- Actual electricity tariffs, payroll rules, hospital charges, examination grace-mark rules, and attendance policies may differ by institution or organization.
- The currency conversion program uses an exchange rate entered by the user; it does not fetch live exchange rates.
- The ATM program is a classroom simulation and is not connected to a real bank.
